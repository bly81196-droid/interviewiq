# InterviewIQ 🚀
An AI-powered mock interview platform designed to help candidates practice and evaluate their answers.

## Features ✨
- Resume upload and job role selection.
- AI-generated interview questions.
- Smart evaluation with score and detailed feedback (Strengths & Areas for Improvement).

## Tech Stack 🛠️
- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- AI Integration: Google GenAI
